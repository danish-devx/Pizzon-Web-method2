🍕 Pizzon Web Recipes App

A modern and responsive recipe web application where users can explore a variety of recipes with an interactive UI and powerful filtering options.

🌐 Live Demo

👉 https://danish-devx.github.io/Pizzon-Web-method2/

---

📌 Features

- 🔍 Search recipes by name
- 🎯 Filter by difficulty (Easy, Medium, Hard)
- 🌍 Filter by cuisine
- 📄 Detailed recipe view page
- ⏭️ "Show More" pagination system
- ⚡ Fast API-based data fetching
- 📱 Fully responsive design

---

🛠️ Technologies Used

- HTML5
- CSS3 (Custom + Bootstrap 5)
- JavaScript (Vanilla JS)
- REST API (DummyJSON Recipes API)

---

⚙️ How It Works

1. Fetches recipes from an external API
2. Displays recipes in card layout
3. Applies filters dynamically (search, cuisine, difficulty)
4. Stores selected recipe in localStorage
5. Redirects to detail page for full recipe info

---

📁 Project Structure

- "index.html" → Main recipes page
- "recipesInfo.html" → Recipe details page
- "app.js" → Main JavaScript logic
- "style.css" → Custom styling
